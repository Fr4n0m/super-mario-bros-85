## Espanol

### 🎮 Descripcion

Implementacion del clasico **Super Mario Bros** en HTML5 con Phaser.  
El objetivo es superar niveles, evitar enemigos y llegar al castillo final.

### 🧰 Tecnologias

- JavaScript (ES Modules)
- HTML5 + CSS3
- Phaser 3.55.2
- Vite 5 (entorno de desarrollo y build)
- html2canvas

### 🚀 Instalacion y ejecucion local

1. Clona el repositorio.
2. Instala dependencias con `npm install`.
3. Ejecuta el proyecto con `npm run dev`.
4. Abre `http://localhost:5173` en tu navegador.

### 📜 Scripts disponibles

- `npm run dev`: inicia el servidor de desarrollo.
- `npm run build`: genera el build de produccion.
- `npm run preview`: previsualiza el build localmente.

### 🗂️ Estructura del proyecto

- `public/assets/`: sprites, audio, fuentes y estilos.
- `public/scripts/`: logica principal del juego por modulos.
- `index.html`: punto de entrada de la aplicacion.

### 🤝 Contribuciones

Las contribuciones son bienvenidas. Si quieres mejorar el juego:

1. Haz un fork del repositorio.
2. Crea una rama con tu cambio.
3. Abre un PR claro con descripcion, contexto y capturas si aplica.

Todo PR que mejore jugabilidad, rendimiento o legibilidad del codigo es muy bienvenido.

## English

### 🎮 Description

An HTML5 implementation of the classic **Super Mario Bros** built with Phaser.  
The goal is to complete levels, avoid enemies, and reach the final castle.

### 🧰 Tech Stack

- JavaScript (ES Modules)
- HTML5 + CSS3
- Phaser 3.55.2
- Vite 5 (dev server and build tooling)
- html2canvas

### 🚀 Local setup

1. Clone this repository.
2. Install dependencies with `npm install`.
3. Run the project with `npm run dev`.
4. Open `http://localhost:5173` in your browser.

### 📜 Available scripts

- `npm run dev`: starts the development server.
- `npm run build`: creates the production build.
- `npm run preview`: previews the production build locally.

### 🗂️ Project structure

- `public/assets/`: sprites, audio, fonts, and styles.
- `public/scripts/`: modular game logic.
- `index.html`: application entry point.

### 🤝 Contributing

Contributions are encouraged. To contribute:

1. Fork the repository.
2. Create a feature/fix branch.
3. Open a clear PR with context and screenshots when relevant.

PRs that improve gameplay, performance, or code quality are highly appreciated.
